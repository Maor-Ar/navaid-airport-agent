30-second pitch

Navaid is a local-first airport investment analyst. We ingest public FAA/BTS files into DuckDB. Python engines compute a peer-relative Terminal Expansion Opportunity Index with a full waterfall. Gemini reconstructs follow-ups, decomposes compound questions, and narrates — it never ranks. A number lock strips any digit that was not in tool JSON. Chat, Gradio, and the site share one FastAPI /ask contract with an assumptions envelope on every answer.

Thesis: terminal renovations are profitable where they unlock unused capacity. Busy is not investable. Landside-bound airports score high. Airside/curfew/slots are penalized. Profit is a capacity-unlock proxy, not PFC/NPV.

  2. Decompose into closed intents; execute all of them.
  3. Plan + run tools even if Gemini is off (template narration).
  4. Number lock every digit against tool JSON / traces.

Scoring — say this out loud

TEOI is peer-relative. Min-max inside S. Weights sum to 1. Missing feature → drop-and-renormalize. Then multiply by constraint.

TEOI = 100 * (0.22 demand + 0.18 congestion + 0.18 landside + 0.15 unmet + 0.12 yield + 0.10 growth + 0.05 capital) * multiplier

Constraint×One-liner
Landside1.00Building binds; terminal capex unlocks capacity
Mixed0.75Part building, part airfield/policy
Airside0.40Slots / runway / curfew / ATC; more terminal does not create slots
Demand-bound0.30Weak catchment; expansion is speculative

Unmet

max(0, implied − served). LF gap uses threshold 0.85. Leakage only if LF ≥ 0.85 and a same-CBSA peer is growing faster. If SFO’s LF is below 0.85, leakage is qualitative (OAK/SJC), not in the number. TAF 10-year gap can still be the numeric unmet. Slot/curfew still bind.

Long-haul

T-100 segments, not O&D. Default 4000 km (Eurocontrol). Report flight-segment share and passenger share. Cargo out unless the user said “include cargo”. ANC→JFK ≈ 5420 km / 3370 mi. Warehouse sample ≠ full-year enplanements.

Congestion

No fake composite. Delay %, arrival delay, cancel %, ops/runway, live FAA, constraint, curfew. LA → LAX not metro. Santa Ana → SNA not SAT. SNA is curfew-capped; LAX wins delay volume.

The four questions — model answers

New England terminal expansion

Peer set is New England (CT, ME, MA, NH, RI, VT). TEOI is relative, not “biggest wins.” BOS is scale and often mixed. Regionals (BDL, PVD, PWM, MHT) can rank as landside-bound. PWM is Portland Maine, not PDX. Rank 1 is strongest terminal-expansion candidate in this set. Waterfall is on the traces.

LA vs Santa Ana congestion

LA → LAX. Santa Ana → SNA, not SAT. Axis-by-axis: LAX usually wins delay volume; SNA is high-utilization and curfew-capped (airside). No single congestion score. Terminal at SNA does not buy hours after curfew.

Anchorage long-haul

Threshold 4000 km on T-100 segments. Quote flight-segment share and passenger share. Cargo excluded unless asked. Sample warehouse, not every cargo/connecting itinerary. ANC→JFK ~5420 km. International share is a separate number.

SFO unmet

Unmet = LF gap + TAF gap + leakage, each clamped at 0. Leakage to OAK/SJC only if LF ≥ 85%. If LF is lower, say that leakage is qualitative and the numeric gap may be the TAF forecast. Slot/curfew still matter; a forecast gap is not a missing concourse.
