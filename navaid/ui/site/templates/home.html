Investment thesis

The assignment is not “which airport is busiest.” It is where modernization is most likely to be profitable because renovations unlock unused capacity. Busy can already be maxed on slots, curfew, or a weak catchment.

  • Landside ×1.00

    Landside-bound

    Gates, holdrooms, security, bag claim, curb. Terminal capex can raise throughput. High TEOI.

  • Airside ×0.40

    Airside-bound

    Runways, slots, weather, ATC, noise curfew. More terminal does not create slots. Score penalized; the answer must say so.

  • Mixed ×0.75

    Mixed

    Part building, part airfield or policy. Terminal helps, but not the whole bind.

  • Demand-bound ×0.30

    Demand-bound

    Weak catchment, low load factor, leakage already served nearby. Expansion is speculative.

TEOI is a comparison, not a grade

A 70 in New England is “high versus these airports.” It is not a score against every US hub. Change the group and the same airport’s TEOI changes.

  • 1 · Peer set S

    Who you asked about

    New England, or the airports named in the question. Min-max, TEOI, and rank exist only inside this group.

  • 2 · Min-max

    Highest in S = 1, lowest = 0

    Ask only BOS and every feature becomes 0.5, so mixed × 0.75 prints ~37. Same airport, different set, different score.

  • 3 · Expansion rank

    Ordinal after the formula

    EXPANSION_RANK is the intent. Expansion rank is 1, 2, 3… after constraint multipliers — not FAA hub size.

Questions the brief requires

  1. EXPANSION_RANK Which airports in New England are strong candidates for terminal expansion?

    BOS is scale. BDL, PVD, PWM, MHT can win as landside-constrained regionals. Peer-relative, not “biggest wins.” PWM is Portland Maine, not PDX.

  2. CONGESTION_COMPARE Compare LA and Santa Ana airport congestion levels.

    LAX wins absolute delay volume; SNA is high-utilization and curfew-capped. No fake single congestion score. “LA” → LAX; “Santa Ana” → SNA, not SAT.

  3. LONGHAUL_SHARE What is the percentage of long haul flights out of Anchorage airport?

    Default Eurocontrol >4000 km on T-100 segments. Also >6h and international share. Cargo out unless asked. ANC→JFK is ~5420 km.

  4. UNMET_DEMAND What is the unmet flight demand in SFO airport and why?

    High load factors, leakage to OAK/SJC, delay, slot/curfew. Much of the gap is airside/policy, not a missing concourse. Unmet is max(0, implied − served).

How an answer is produced

  1. Reconstruct follow-ups into a standalone question from session memory.
  2. Decompose compound questions so every subgoal is answered.
  3. Engines compute TEOI, unmet, long-haul, congestion — same input, same output.
  4. Number lock rejects any digit that was not in a tool payload.
  5. Narrate from traces. Gemini never ranks.

Every ranking answer includes the full TEOI waterfall. The workbench keeps steps, rankings, traces, engine tables, citations, and unsupported_parts on that answer card as collapsed details. The envelope stays in the sidebar. Same JSON as POST /ask.
